## PR #29 Third-party licence notices, and iCloud container creation on the Mac

Two of the 0.1.0 blockers.

**Third-party licence notices.** MIT, BSD and Apache ask that their notice travel with the program. `npm run licenses` (`scripts/licenses.mjs`) writes every shipped npm package and every crate the app links (all platforms), with their licence files, to `public/third-party-licenses.txt` (1204 packages, ~1.6 MB, identical texts written once). Settings → About → **Third-party licences** opens it in a dialog, fetched only when opened. CI runs `npm run licenses -- --check`, so a dependency change without regenerating fails.

**Mac creates the iCloud container.** With a new optional secret `MACOS_PROVISION_PROFILE` (a Developer ID provisioning profile for `tech.grimfeld.synesis` carrying iCloud), the macOS release jobs embed the profile and the iCloud entitlements (`src-tauri/macos/Synesis.entitlements`, team id filled in), and the Mac app asks `URLForUbiquityContainerIdentifier` like the iPhone. Without the secret nothing changes: macOS kills an app that claims iCloud with no profile, so the entitlements are left out. ADR 0022 notes it.

Checked: typecheck, 482 unit tests, `licenses --check`, full Cypress suite 422/422 (before this branch) and `updater.cy.ts` 6/6 on it (new notices test included). The Mac part compiles only on macOS and is proven by a release with the secret set.
